`reskate.server` is the session's authority acting on its players. It works only in a plugin's **server copy**. Every function needs the `server` permission, except the [park mod](#park-mods) functions, which need `server.parks`. See [permissions](/plugins/permissions) and [manifest](/plugins/manifest).

## Server copies

A plugin whose manifest says `"side": "server"` or `"side": "both"` has a server copy, which runs as the session's authority:

- **On a lobby's host.** While a player's game hosts a lobby, the server copies of their plugins run on that game beside the client copies. Each has its own id, `<folder>@server` ([`reskate.id`](/plugins/api/base)), for its log lines, its storage, its console commands and all it holds in the game, so it shares nothing with the client copy. They stop when the game stops hosting, and the client copies carry on untouched.
- **On a dedicated server**, from the `Plugins` folder beside the server.

In a server copy, `reskate.side` is `"server"`; in a client copy it is `"client"`. Branch on it in a plugin for both sides:

```lua
-- Needs the "server" and "session.read" permissions.
if reskate.side == "server" then
    reskate.on("player_joined", function(player)
        reskate.server.say("Welcome, " .. player.name .. ".")
    end)
end
```

Calling a `reskate.server` function in a client copy raises an error, as does calling one without the `server` permission.

## Lobby host and dedicated server

The functions do not all work the same way in both places.

| Function | On a lobby's host | On a dedicated server |
| --- | --- | --- |
| `kick` | The player is disconnected and cannot join this lobby again. The host cannot be kicked. | The player is dropped from the server. |
| `say` | A line in the host's own chat, under the host's name, needing a session. | A line from the server to every player. |
| `tell` | Not available: a lobby has no private chat. It returns `false` and says to message that player's copy instead. | A line to that player only. |
| `move` | The player's game moves their skater (only a player in the world, not the host). | The same: the player's game makes the move. |
| `ban`, `unban` | Not available: they return `false` and `"unavailable here"`. | The server's own ban list, as the console's `ban` and `unban`. |
| `player.permissions`, `player:apply_permissions` | Not available: `permissions` is `nil`, and applying returns `false` and `"unavailable here"`. | What the player may do on the server, as the console's `lock`. |
| `player.role` | Not available: `role` is `nil`. | The player's role in the server's `data/roles.json`, as the console's `role` gives it. |
| `parks`, `park_spawn`, `park_remove` | Not available: `parks` is empty, and spawning or removing returns `false` and `"unavailable here"`. | The server's park mods, as the console's `park-mod`. |

Chat lines from `say` and `tell` start with the plugin's name in brackets (`[My Plugin] ...`): the `name` in its `manifest.json`, or its folder's name without one.

## Players

A player is a player's id (`"7656..."`, a string) or a player table with an `id`, such as `reskate.session.players()` and the `player_joined` event give. Anything else raises an error.

### `reskate.server.kick(player, why)`

Removes a player from the session.

<ParamField path="player" type="string or table" required>The player.</ParamField>
<ParamField path="why" type="string">At most 120 characters, shown to the player: "You were removed from the session: " (lobby) or "Removed from the server: " (dedicated server), then `why`.</ParamField>

<ResponseField name="ok" type="boolean">True when the player was removed.</ResponseField>
<ResponseField name="why" type="string">Why not: on a lobby's host `"the host cannot be kicked"` or `"that player is not in the session"`; on a dedicated server `"that player is not on the server"`.</ResponseField>

```lua
-- Players this server does not want, by id, kept in the plugin's storage.
reskate.on("player_joined", function(player)
    local banned = reskate.storage.get("banned") or {}
    if banned[player.id] then
        reskate.server.kick(player, "you are banned here")
    end
end)
```

<Warning>A kick on a lobby's host also keeps the player out of that lobby until it closes.</Warning>

<Note>Needs the `server` permission and a server copy. The example also needs `session.read` and `storage`.</Note>

### `reskate.server.say(text)`

A chat line to everyone in the session.

<ParamField path="text" type="string" required>1 to 200 characters, not starting with `/`.</ParamField>

<ResponseField name="ok" type="boolean">True when the line was sent.</ResponseField>
<ResponseField name="why" type="string">Why not: `"one line a second"`, or on a lobby's host `"not in a session"` or the chat's own reason.</ResponseField>

```lua
reskate.server.say("Round two starts in 10 seconds.")
```

An empty line, one starting with `/`, or one longer than 200 characters raises an error.

<Note>Needs the `server` permission and a server copy. One line a second.</Note>

### `reskate.server.tell(player, text)`

A chat line to one player only. Only a dedicated server has it: a lobby has no private chat. On a lobby's host, send that player's copy a message with [`reskate.net.send`](/plugins/api/session) and show it there.

<ParamField path="player" type="string or table" required>The player.</ParamField>
<ParamField path="text" type="string" required>1 to 200 characters.</ParamField>

<ResponseField name="ok" type="boolean">True when the line was sent.</ResponseField>
<ResponseField name="why" type="string">Why not: `"that player is not on the server"`, or on a lobby's host `"a lobby has no private chat: send that player's copy a message (reskate.net.send) and show it there"`.</ResponseField>

```lua
-- Needs "net.session" too, for the lobby's way.
local ok = reskate.server.tell(player, "You are it.")
if not ok then reskate.net.send(player, "You are it.") end -- its copy shows it
```

<Note>Needs the `server` permission and a server copy.</Note>

### `reskate.server.move(player, position)`

Moves a player's skater, on a lobby's host and on a dedicated server alike. The player's game makes the move, as for the console's `tpall` and `tphere`.

<ParamField path="player" type="string or table" required>The player.</ParamField>
<ParamField path="position" type="vector" required>Where the skater goes. Finite, within 100 km.</ParamField>

<ResponseField name="ok" type="boolean">True when the teleport was sent.</ResponseField>
<ResponseField name="why" type="string">Why not: on a lobby's host `"that player is not in the world"` (or not in the session, or the host) or `"it could not be sent"`; on a dedicated server `"that player is not on the server"`.</ResponseField>

```lua
local start = vector.create(120, 4, -36)
for _, p in reskate.session.players() do
    reskate.server.move(p, start)
end
```

<Note>Needs the `server` permission and a server copy. A position that is not finite raises an error.</Note>

### `reskate.server.ban(player)`

Bans a player from a dedicated server, whether they are connected or not, as the server console's `ban` does: a connected player is dropped with "You were banned from this server.", and the ban is saved in the server's ban list.

<ParamField path="player" type="string or table" required>The player: a player table, or any player's SteamID64 (17 digits starting `7656119`), here or not.</ParamField>

<ResponseField name="ok" type="boolean">True when the player is banned afterwards, including one who was banned already.</ResponseField>
<ResponseField name="why" type="string">Why not: the console's answer, such as `"Enter a connected player or a SteamID64 (17 digits starting 7656119)."`; on a lobby's host `"unavailable here"`.</ResponseField>

```lua
-- Three kicks and you are banned.
local function strike(player)
    local kicks = reskate.storage.add("kicks." .. player.id, 1)
    if kicks >= 3 then
        reskate.server.ban(player)
    else
        reskate.server.kick(player, "warning " .. kicks .. " of 3")
    end
end
```

Each ban the plugin makes is written to the server's log.

<Note>Needs the `server` permission and a server copy on a dedicated server. The example also needs `storage`.</Note>

### `reskate.server.unban(player)`

Lifts a dedicated server's ban on a player, as the server console's `unban` does. The player may also join again at once if they were kicked.

<ParamField path="player" type="string or table" required>The player: a player table or a SteamID64.</ParamField>

<ResponseField name="ok" type="boolean">True when the player is not banned afterwards, including one who was not banned.</ResponseField>
<ResponseField name="why" type="string">Why not: on a lobby's host `"unavailable here"`.</ResponseField>

```lua
reskate.server.unban("76561198000000001")
```

<Note>Needs the `server` permission and a server copy on a dedicated server.</Note>

## Park mods

A dedicated server can have park mods set up: parks built in the Park Editor and shipped as mods, each bound to one map (`maps.park_mods` in `ReSkateServer.json`, or the console's `park-mod config add`). The server copy can list them and spawn or remove them, as the console's `park-mod add` and `remove` do: with the server's limits on parks and objects, the check that a park belongs on the map running now, and the chat line to everyone. The server's log says `[parks] <name> spawned (...) by plugin <id>`.

These functions need the `server.parks` permission, not `server`, and a server copy on a dedicated server.

A park mod's name is its own in the server's setup: 1 to 16 of `a-z`, `0-9`, `-` and `_`. Anything else raises an error.

### `reskate.server.parks()`

The park mods the server has set up.

<ResponseField name="parks" type="table">
A list of tables:

- `name` (string): the park mod's name.
- `map` (string): the map it belongs on, as the server names it (`"San Vansterdam"`).
- `here` (boolean): `true` when it belongs on the map running now, so it can be spawned.
- `spawned` (boolean): `true` while it is out.
- `objects` (number): how many objects it has out (0 while it is not spawned).
- `minutes_left` (number): minutes until it goes; 0 when it stays until removed, or is not spawned.

Empty on a lobby's host.
</ResponseField>

```lua
for _, park in reskate.server.parks() do
    if park.here and not park.spawned then reskate.log(park.name .. " could come out") end
end
```

<Note>Needs `server.parks` and a server copy on a dedicated server. Each call counts as a `reskate.server` call.</Note>

### `reskate.server.park_spawn(name, minutes)`

Spawns a park mod for every player.

<ParamField path="name" type="string" required>The park mod's name.</ParamField>
<ParamField path="minutes" type="number">How long it stays, 1 to 1440. Without it, it stays until removed (or until the map changes).</ParamField>

<ResponseField name="ok" type="boolean">True when it was spawned.</ResponseField>
<ResponseField name="why" type="string">Why not, as `park-mod add` says it: `"street is already spawned."`, `"street belongs on Isle of Grom, and the server is on San Vansterdam."`, `"there is no park mod called "street" (park-mod list)."`, the limits on parks and objects; on a lobby's host `"unavailable here"`.</ResponseField>

```lua
-- The race's park, out for the race and a little after.
local ok, why = reskate.server.park_spawn("immi-race2", 10)
if not ok then reskate.log("no park: " .. why, "warn") end
```

<Tip>Players' games need a few seconds to load a park's objects after it is spawned. Wait before moving anyone onto it.</Tip>

<Note>Needs `server.parks` and a server copy on a dedicated server. A name that is not a park mod's, or minutes outside 1 to 1440, raises an error. Each call counts as a `reskate.server` call.</Note>

### `reskate.server.park_remove(name)`

Removes a spawned park mod.

<ParamField path="name" type="string" required>The park mod's name.</ParamField>

<ResponseField name="ok" type="boolean">True when it was removed.</ResponseField>
<ResponseField name="why" type="string">Why not: `"street is not spawned."`, `"there is no park mod called "street" (park-mod list)."`; on a lobby's host `"unavailable here"`.</ResponseField>

```lua
reskate.server.park_remove("immi-race2")
```

<Note>Needs `server.parks` and a server copy on a dedicated server. Each call counts as a `reskate.server` call.</Note>

## Player permissions

On a dedicated server, the server copy decides what each player may do, as the server console's `lock` does. A player table (from `reskate.session.players()`, the `player_joined` event and the others) has two names of its own for this in a server copy: `permissions` and `apply_permissions`.

| Permission | When it is `false` |
| --- | --- |
| `noclip` | No noclip or teleporting. |
| `nobail` | No No Bail. |
| `boosts` | No boosts. |
| `tuning` | No physics tuning of the player's own. |
| `objects` | No placing objects. |
| `ollies` | No ollies. |

### `player.permissions`

What the server holds for the player now: a read-only table with each permission above, `true` where the player may. It is read from the server each time you read it.

<ResponseField name="permissions" type="table or nil">
`nil` for a player the server cannot hold permissions for (not a player's SteamID64), and on a lobby's host.
</ResponseField>

```lua
local p = player.permissions
if p and not p.noclip then reskate.server.tell(player, "Noclip is off for you here.") end
```

Reading it outside a server copy, or without the `server` permission, raises an error. Each read counts as a `reskate.server` call (see [limits](#limits)).

### `permissions:clone()`

A copy of a permissions table that you can change, for `apply_permissions`. The table `player.permissions` gives is read-only.

<ResponseField name="copy" type="table">The same six permissions, each `true` or `false`.</ResponseField>

### `player:apply_permissions(permissions)`

Makes the player's permissions exactly these. They hold as an admin's locks do: a throwdown ending does not lift them.

<ParamField path="permissions" type="table" required>All six permissions, each `true` or `false`, and nothing else: start from `player.permissions:clone()`, so none is left out by mistake. A permission that is missing or not a boolean, or a name that is not a permission, raises an error.</ParamField>

<ResponseField name="ok" type="boolean">True when the permissions were applied.</ResponseField>
<ResponseField name="why" type="string">Why not: `"not a player's SteamID64"`; on a lobby's host `"unavailable here"`.</ResponseField>

```lua
-- No noclip or boosts while the race runs; the rest as it was.
reskate.on("player_joined", function(player)
    local p = player.permissions
    if not p then return end
    local race = p:clone()
    race.noclip, race.boosts = false, false
    player:apply_permissions(race)
end)
```

<Note>Needs the `server` permission and a server copy on a dedicated server. The example also needs `session.read`. Each call counts as a `reskate.server` call.</Note>

## Player roles

A dedicated server gives each player a role (`data/roles.json`, and the console's `role <SteamID64> <role>`): the one given them, or else the server's default role. In a server copy, a player table's `role` says which, so a plugin can let its own commands follow the server's roles instead of keeping a list of its own.

### `player.role`

The player's role now: a read-only table, read from the server each time you read it.

<ResponseField name="name" type="string">The role's name, such as `"player"`, `"moderator"` or `"admin"`.</ResponseField>
<ResponseField name="rank" type="number">Its rank, 0 to 1000. With the roles a new server starts with: `player` and `muted` 0, `vip` 10, `moderator` 50, `admin` 100.</ResponseField>
<ResponseField name="staff" type="boolean">Whether the role gives any of the server's commands (such as `kick`): `true` for `moderator` and `admin` on a new server.</ResponseField>

`role` is `nil` for a player with no role (one given none, on a server with no default role), for the server itself, and on a lobby's host.

```lua
-- Only moderators and above edit the tracks.
local function may_edit(player)
    local role = player.role
    return role ~= nil and role.rank >= 50
end
```

Reading it outside a server copy, or without the `server` permission, raises an error. Each read counts as a `reskate.server` call (see [limits](#limits)).

## Limits

<Note>
A server copy makes at most 20 `reskate.server` calls a second, reading `player.permissions` and `player.role`, `apply_permissions` and the park mod functions included; the 21st raises an error. `say` also has its own limit of one line a second, which returns `false`. See [limits](/plugins/limits).
</Note>
