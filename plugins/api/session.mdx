This page covers the multiplayer session: who is in it, spectating a player and the session's world (`reskate.session`, which needs `session.read`), other players' skaters, touching them, hiding them and rays at them (`session.skaters`), tags beside their nametags (`session.nametags`), their voice volume (`voice.control`), and messages between the copies of your plugin on every player's game (`reskate.net.send` and the `message` event, which need `net.session`). See [permissions](/plugins/permissions).

## Players

A player is a table:

| Field | Type | What it is |
| --- | --- | --- |
| `id` | string | Their SteamID64, as a string: `"76561197960287930"`. |
| `name` | string | Their name. |
| `me` | boolean | `true` for the local player. |
| `host` | boolean | `true` for the player who hosts the lobby. On a dedicated server nobody is the host. |
| `server` | boolean | `true` only for a message from the session's authority (see below). |

Functions that take a player take either the table or its `id` string.

The session is read four times a second, so a player who just joined may take up to a quarter of a second to appear. The `player_joined` and `player_left` events (they need `session.read`) say who came and went; see [events](/plugins/events).

### `reskate.session.active()`

<ResponseField name="active" type="boolean">`true` while the player is in a multiplayer session.</ResponseField>

### `reskate.session.is_dedicated()`

<ResponseField name="dedicated" type="boolean">`true` when the session is on a dedicated server, `false` in a player's lobby or outside a session.</ResponseField>

### `reskate.session.players()`

Everyone in the session, the local player first.

<ResponseField name="players" type="table">A list of players; empty outside a session.</ResponseField>

```lua
for _, p in reskate.session.players() do
    reskate.log(p.name .. (p.me and " (you)" or "") .. (p.host and " (host)" or ""))
end
```

### `reskate.session.me()`

<ResponseField name="me" type="table or nil">The local player, or `nil` outside a session.</ResponseField>

### `reskate.session.host()`

<ResponseField name="host" type="table or nil">The player who hosts the lobby, or `nil` outside a session and on a dedicated server.</ResponseField>

```lua
local host = reskate.session.host()
if host and host.me then
    reskate.log("you host this lobby")
end
```

<Note>`active`, `is_dedicated`, `players`, `me` and `host` need `session.read`.</Note>

On a plugin's server copy on a dedicated server, `active` and `is_dedicated` are `true`, `players` lists the players on the server, and `me` and `host` are `nil`: the server is none of them.

## Spectating and the world

### `reskate.session.spectate(player)`

Watches a session player's skater with the game's Spectate camera, as the party menu's Spectate does, or stops watching.

<ParamField path="player" type="string">A player's id (`"7656..."`). `nil`, nothing or `"0"` stops a Spectate started this way.</ParamField>

Returns nothing. A player whose skater cannot be watched now is ignored, and so is the player Spectate already watches.

```lua
-- Watch whoever's turn it is; back to your own skater on yours.
local function watch(turn)
    if turn.me then reskate.session.spectate(nil) else reskate.session.spectate(turn.id) end
end
```

A `player` that is not a string of digits (or a number) raises an error. Pass the id as a string: a Lua number cannot hold a SteamID64 exactly. Unlike `reskate.camera.follow`, it does not take a player table.

<Note>
Needs `session.read`. Spectate takes the camera from a plugin's view while it runs (see [camera](/plugins/api/camera)). A Spectate started with `spectate` or `camera.follow` is the same one: stopping either way ends it. It does not end when your plugin stops: stop it in an `unload` handler.
</Note>

### `reskate.session.world()`

The world the local player is in, for a game mode that matches players in the same world.

<ResponseField name="world" type="table">
<Expandable title="fields">
<ResponseField name="world" type="string">The world's id, as a string. In a session it is the session's world; outside one, the world the game generated for the level. It changes whenever the map or the session changes. `"0"` when there is none.</ResponseField>
<ResponseField name="barred" type="boolean">True in a session when the local player's game is barred from games with others: the dedicated server flagged their game speed, or the host or server found their mods change scoring or physics.</ResponseField>
<ResponseField name="map" type="string">The loaded map's name. Empty when none is loaded.</ResponseField>
</Expandable>
</ResponseField>

```lua
local here = reskate.session.world()
if here.barred then
    reskate.log("your mods keep you out of scored games here", "warn")
end
reskate.net.send("all", reskate.json.encode({world = here.world})) -- net.send needs net.session
```

<Note>Needs `session.read`. On a server copy, `world` is `"0"`, `barred` is false and `map` is empty.</Note>

## Other players' skaters

### `reskate.session.skaters()`

Where the other players' skaters are, as the session last heard. The local skater is not in it: use [`reskate.skater.get`](/plugins/api/skater).

<ResponseField name="skaters" type="table">
A list of tables:

- `id` (string): the player's id.
- `position` (vector): the skater's position, in world metres.
- `heading` (number): the way it faces, in radians, as the local skater's heading.
- `age_ms` (number): how old that pose is, in milliseconds.
</ResponseField>

```lua
reskate.on("draw", function(d)
    for _, s in reskate.session.skaters() do
        d:world_text(s.position + vector.create(0, 2.4, 0), "TARGET", {align = "centre", colour = "#ff4040"})
    end
end)
```

<Note>Needs `session.skaters`.</Note>

### `reskate.session.joint(player, joint)`

Where one of another player's joints is in the world, as your game draws their skater.

<ParamField path="player" type="string or table" required>The player, by id or player table.</ParamField>
<ParamField path="joint" type="number or string" required>A joint, as [`reskate.skater.joint`](/plugins/api/skater) takes it: 0 to 394, or `"right_hand"`, `"left_hand"`, `"head"`, `"hips"` or `"spine"`.</ParamField>

<ResponseField name="joint" type="table or nil">`{position, rotation, scale}`, as `reskate.skater.joint` gives it. `nil` while your game does not draw that player, and on the first call: asking keeps the joint read for 2 seconds, so call it every tick. At most 64 joints of other players are read at once, for every plugin together.</ResponseField>

```lua
-- A marker over each player's head.
reskate.on("draw", function(d)
    for _, p in reskate.session.skaters() do
        local head = reskate.session.joint(p.id, "head")
        if head then d:world_text(head.position + vector.create(0, 0.4, 0), "IT", {colour = "#ff4040"}) end
    end
end)
```

<Note>Needs `session.skaters`. A `player` that is not a player's id, or a joint that is not one of those, raises an error.</Note>

### `reskate.session.tag(player, text, colour)`

Puts a short tag beside a player's nametag, or takes yours away. Only this player sees it: it changes nothing on anyone else's game.

<ParamField path="player" type="table or string" required>A player, or their id.</ParamField>
<ParamField path="text" type="string">At most 16 characters of printable ASCII. `nil` or `""` takes your tag away.</ParamField>
<ParamField path="colour" type="number" default="white">A number `0xRRGGBBAA`.</ParamField>

```lua
reskate.session.tag(player, "IT", 0xFF4040FF)
-- later
reskate.session.tag(player, nil)
```

<Note>
Needs `session.nametags`. Raises an error for a player that is not one, text over 16 characters or not printable, and a colour that is not a whole number from `0` to `0xFFFFFFFF`. When several plugins tag the same player, one tag shows. Your tags go away when your plugin stops.
</Note>

## Touching, hiding and rays at players

For tag, infection or prop hunt: when your skater touches another player's, another player's skater hidden on your screen, and a ray that hits players.

Each skater's body is a set of capsules around its parts, as your game draws it: `"head"`, `"body"` (hips to neck), `"left_arm"`, `"right_arm"` (shoulder to hand), `"left_leg"`, `"right_leg"` (hip to foot) and `"board"` (the deck, while it is drawn). Your own skater's body is read each time your pose is sent to the other players, and moves with your skater in between. Bodies are read only in a multiplayer session, and only while a plugin uses them: the first tick or two after you start, nothing is touched or hit.

Each game sees its own skater's touches. To tell everyone, send a [message](#messages): the player you touched hears it on their game too.

### `reskate.session.touch(on, reach)`

Turns the [`touch` and `touch_end` events](/plugins/events#touch) on or off for your plugin.

<ParamField path="on" type="boolean" default="true">True (or nothing) to hear touches. False stops them: `touching` is empty again, and no `touch_end` fires for the players touched then.</ParamField>
<ParamField path="reach" type="number" default="0.05">How near counts as touching, in metres between the two bodies' surfaces: 0 to 1. Calling it again while on changes the reach.</ParamField>

Returns nothing.

```lua
-- Tag: whoever is it passes it on by touching someone.
local it = nil -- the id of the player who is it
reskate.session.touch(true, 0.1)
reskate.on("touch", function(e)
    if it == reskate.session.me().id then
        it = e.player
        reskate.net.send("all", reskate.json.encode({it = it})) -- net.send needs net.session
    end
end)
```

<Note>Needs `session.skaters`. A reach that is not 0 to 1 raises an error. At most 64 players are touched at once: past that, a touch waits until one of them is apart.</Note>

### `reskate.session.touching()`

The players your skater touches now, while touching is on.

<ResponseField name="touching" type="table">
A list of tables, as the [`touch` event](/plugins/events#touch) gives them:

- `player` (string): the player's id.
- `part` (string): the part of your skater nearest theirs.
- `their_part` (string): the part of their skater nearest yours.
- `distance` (number): the gap between the two parts, in metres: 0 where they overlap.
- `position` (vector): the point halfway across that gap, in the world.
</ResponseField>

<Note>Needs `session.skaters`. Empty while touching is off.</Note>

### `reskate.session.hide(player, hidden)`

Hides another player's skater on your screen, or shows it again. Only your game changes: they still see themselves, and everyone else still sees them.

While hidden, their skater and board are not drawn, their sounds do not play, their nametag and their marker on the map are gone, they cannot be spectated, and they are not solid to your skater. Their body is still there for `touch` and `raycast`.

<ParamField path="player" type="string or table" required>The player, by id or player table.</ParamField>
<ParamField path="hidden" type="boolean" default="true">True (or nothing) hides them; false shows them again.</ParamField>

<ResponseField name="ok" type="boolean">Whether it was done.</ResponseField>
<ResponseField name="why" type="string">`"at most 256 players are hidden"`: the most for every plugin together.</ResponseField>

```lua
-- Prop hunt: the hiders' skaters are hidden, and a prop of your own stands in for each (reskate.entities.set).
local function hide_hiders(hiders)
    for _, id in hiders do
        reskate.session.hide(id)
    end
end
```

<Note>Needs `session.skaters`. A player stays hidden while any plugin hides them. Your plugin's go when it stops.</Note>

### `reskate.session.hidden()`

<ResponseField name="players" type="table">The ids (strings) of the players your plugin hides.</ResponseField>

<Note>Needs `session.skaters`.</Note>

### `reskate.session.raycast(from, to, options)`

The first other player's body a ray meets. Your own skater is never hit; hidden players are.

<ParamField path="from" type="vector" required>Where the ray starts, in world metres.</ParamField>
<ParamField path="to" type="vector" required>Where it ends. At most 1000 m from `from`.</ParamField>
<ParamField path="options.world" type="boolean" default="true">True: the world blocks the ray, as [`reskate.world.raycast`](/plugins/api/world) meets it. Anything it meets more than 0.4 m before the player blocks (closer than that, the player's own collision can be what it meets). False: the ray goes through the world.</ParamField>

<ResponseField name="hit" type="table or nil">
`nil` when no player is hit, or the world is in the way. Otherwise:

- `player` (string): the player's id.
- `part` (string): the part hit, one of the parts above.
- `position` (vector): where the ray meets the part's surface.
- `distance` (number): how far that is from `from`, in metres.
</ResponseField>

```lua
-- Who the camera looks at, within 50 m (camera.get needs the camera permission).
local cam = reskate.camera.get()
local hit = cam and reskate.session.raycast(cam.position, cam.position + cam.forward * 50)
if hit then reskate.log("looking at " .. hit.player .. "'s " .. hit.part) end
```

<Note>Needs `session.skaters`, and no `world.raycast`. Each call counts towards the 64 raycasts a tick, with `reskate.world.raycast`'s. A ray longer than 1000 m, or a raycast past those 64, raises an error. Collision is loaded only near your skater, so far from it the world does not block.</Note>

## Voice

### `reskate.voice.set_volume(player, volume)`

Sets how loud a player's voice chat is for the local player. It changes only what this player hears.

<ParamField path="player" type="table or string" required>A player, or their id.</ParamField>
<ParamField path="volume" type="number" required>0 mutes them, 1 is as heard, up to 10.</ParamField>

<ResponseField name="ok" type="boolean">`true` when it was set.</ResponseField>
<ResponseField name="why" type="string">Why not, when `ok` is false: "more than 10 changes in a second", or the session's own answer when it refused.</ResponseField>

```lua
local ok, why = reskate.voice.set_volume(player, 0)
if not ok then reskate.log("could not mute: " .. why) end
```

<Note>Needs `voice.control`. At most 10 changes a second; past them it returns `false` and why. Raises an error for a player that is not one, and a volume outside 0 to 10.</Note>

## Messages

Your plugin talks to the copies of itself on the other players' games, and to its server copy, with `reskate.net.send`. Messages go only to the same plugin: two copies are the same plugin when their `manifest.json` gives the same `name` (case does not matter), whatever their folders are called. A plugin with no `name` in its `manifest.json` uses its folder's name.

The session says who sent a message: a plugin cannot pretend to be another player, or the server.

### `reskate.net.send(to, message)`

Sends a message.

<ParamField path="to" type="string or table" required>
Who gets it:

- `"all"`: every other player's copy (and the server copy).
- a player, or a player's id: that player's copy only.
- `"server"`: the plugin's server copy only: on the lobby's host, or on the dedicated server. A server copy cannot send to `"server"`: it is the server.
</ParamField>
<ParamField path="message" type="string or buffer" required>At most 4082 bytes. Text, or binary in a string or a `buffer`.</ParamField>

<ResponseField name="sent" type="boolean">`true` when it was sent; `false` outside a session, or when too many messages wait to go out.</ResponseField>

```lua
reskate.net.send("all", reskate.json.encode({kind = "score", value = 1250}))

reskate.on("message", function(from, text)
    local ok, data = pcall(reskate.json.decode, text)
    if ok and data.kind == "score" then
        reskate.console.print(from.name .. " scored " .. data.value)
    end
end)
```

A message is not delivered back to the copy that sent it.

<Note>
Needs `net.session`. A message is at most 4082 bytes, and a plugin sends at most 16 KB a second (each message counts 14 bytes more for its header). Raises an error past those, for `to` that is not `"all"`, `"server"`, a player or a player's id, for `"server"` from a server copy, and for a message that is not a string or a buffer.
</Note>

### The `message` event

```lua
reskate.on("message", function(from, message) end)
```

Fires when a message from another copy of your plugin arrives. It needs `net.session`.

- `from` is the player who sent it. A message from the server copy has `from.server == true`; its `name` is the host's, or `"Server"` on a dedicated server.
- `message` is always a string, even when it was sent as a buffer: use `buffer.fromstring` to read it as one.

```lua
-- the server copy answers pings; the players' copies hear the answer
reskate.on("message", function(from, text)
    if reskate.side == "server" and text == "ping" then
        reskate.net.send(from, "pong")
    elseif from.server and text == "pong" then
        reskate.console.print("the server answered")
    end
end)

reskate.console.command("ping server", "Asks the server copy for a pong", function()
    reskate.net.send("server", "ping")
end)
```

<Warning>
Only `from.server` is a message you can trust to come from the session's authority. Any player can run a changed copy of your plugin and send what they like to `"all"`, to you or to `"server"`: check what arrives, and let the server copy decide what counts.
</Warning>
