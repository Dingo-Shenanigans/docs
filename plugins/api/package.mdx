`reskate.package` reads files from your plugin's own package: its mod folder, the folder that holds `reskate-plugin.json`. It cannot reach anything outside it, and it cannot write. Reading needs no permission.

It also reads and chooses your mod's [variants](#variants): `variants` needs no permission, and `choose` needs the `variants` [permission](/plugins/permissions).

To keep files you write, use [`reskate.files`](/plugins/api/files).

## Paths

A path is relative to the package's root (not to the entry's folder): `"data/spots.json"`, `"sounds/beep.wav"`. A path is refused, with an error, when it:

- is empty, longer than 260 characters, or starts with `/`;
- has a `\`, a `:` (a drive, or a stream), or a character outside printable ASCII;
- has an empty, `.` or `..` folder (`a//b`, `./a`, `a/../b`);
- has a folder or file name that ends in `.` or a space.

After those checks, the path is resolved once more with links and junctions followed, and a path that leads outside the package is refused too.

```lua
pcall(reskate.package.read, "../other-mod/secret.txt") -- false: not a path inside the package
```

### `reskate.package.read(path)`

A file's contents.

<ParamField path="path" type="string" required>The file's path in the package.</ParamField>

<ResponseField name="text" type="string or nil">The whole file, byte for byte, or `nil` when there is no such file (or the path is a folder).</ResponseField>

```lua
local intro = reskate.package.read("data/intro.txt")
if intro then reskate.console.print(intro) end
```

### `reskate.package.read_json(path)`

A JSON file's contents as Lua values: objects become tables with string keys, arrays become lists, `null` becomes `nil`.

<ParamField path="path" type="string" required>The file's path in the package.</ParamField>

<ResponseField name="value" type="any">The file's value, or `nil` when there is no such file.</ResponseField>

```lua
local spots = reskate.package.read_json("data/spots.json") or {}
for _, spot in spots do
    reskate.log(spot.name)
end
```

<Note>Raises an error for JSON that is not valid, has a key twice, or is nested deeper than 64.</Note>

### `reskate.package.list(folder)`

The names in one of the package's folders.

<ParamField path="folder" type="string" default="the package's root">The folder's path in the package. Leave it out, or pass `""`, for the root.</ParamField>

<ResponseField name="names" type="table">A sorted list of names. A folder's name ends in `/`. Names with characters outside printable ASCII are left out. A folder that is not there gives an empty list.</ResponseField>

```lua
for _, name in reskate.package.list("levels") do
    if name:sub(-5) == ".json" then
        local level = reskate.package.read_json("levels/" .. name)
    end
end
```

<Note>
`read` and `read_json` raise an error for a file larger than 16 MB, or one that cannot be read. `list` raises an error for a folder with more than 1000 entries. All three raise an error for a path that breaks the rules above.
</Note>

<Tip>
Pictures ([`d:image`](/plugins/api/overlay)), sounds ([`reskate.audio.play`](/plugins/api/audio)) and modules ([`require`](/plugins/api/base)) also come from the package. `require` looks beside the entry; the others take a path from the package's root.
</Tip>

## Variants

A mod can hold several takes on the same game data, such as several deck models for the one deck every board has. Each is a variant, and one is in the game at a time. Your manifest declares them with [`variants`](/plugins/manifest#variants). These two functions say which variants there are and put one in the game.

### `reskate.package.variants()`

Your mod's variants, and which is in the game.

<ResponseField name="variants" type="table or nil">
`nil` when your manifest declares no variants, when its `variants` could not be read, and on a dedicated server.
<Expandable title="fields">
<ResponseField name="list" type="table">The names of the variants in your mod's variants folder: those in the manifest's `order` first, in that order, then the rest by name. Names are in lower case. An empty list when the folder has none.</ResponseField>
<ResponseField name="chosen" type="string or nil">The variant the player last chose for your mod, or `nil` when none was chosen.</ResponseField>
<ResponseField name="in_play" type="string or nil">The variant in the game now, or `nil` when none of yours is (its variants folder has none, for one).</ResponseField>
</Expandable>
</ResponseField>

ReSkate reads your mod's variants folder again at most every 2 seconds, so a variant added to it shows in `list` within 2 seconds. You can call `variants` every frame, as a menu page does.

```lua
local state = reskate.package.variants()
if state then
    for i, name in state.list do
        local mark = if name == state.in_play then " (in the game)" else ""
        reskate.log(string.format("%d. %s%s", i, name, mark))
    end
end
```

<Note>Needs no permission. `chosen` can differ from `in_play`: a choice is in the game once the mods are applied and the level has loaded again, and a chosen variant that is no longer installed falls back to another.</Note>

### `reskate.package.choose(name)`

Puts one of your mod's variants in the game. The choice is kept for your mod, and it is the one the game loads from then on, also at the next launch.

<ParamField path="name" type="string" required>A name from `variants().list`. Case does not matter.</ParamField>

<ResponseField name="ok" type="boolean">True when the choice is saved.</ResponseField>
<ResponseField name="why" type="string">Why not: `"its mod declares no variants"`, `"its mod has no variant <name>"`, `"the mods are being applied"` or `"the choice could not be saved"`.</ResponseField>

When the variant you choose is not the one in the game, ReSkate applies the mods again at once, and the level being played loads again with it once that is done. `in_play` names it from then on. Choosing the variant already in the game only saves the choice.

```lua
reskate.menu.page("Decks", function(ui)
    local state = reskate.package.variants()
    if not state then return end
    for _, name in state.list do
        if name ~= state.in_play and ui:button("deck_" .. name, "Use " .. name) then
            local ok, why = reskate.package.choose(name)
            if not ok then reskate.log("not now: " .. why) end
        end
    end
end)
```

<Note>Needs the `variants` permission (and `menu` for the example's page). On a dedicated server, `choose` returns `false, "unavailable here"`.</Note>
