---
title: "Getting started"
description: "Install ReSkate, let the launcher set up the game, and start playing, on Windows, Linux or macOS."
---

ReSkate runs from a folder of its own, with its own copy of the game: Steam updating skate. cannot break it. You need your own copy of skate. on Steam, and about 14 GB of free space.

ReSkate supports one game build at a time: Steam build `25414733`. The launcher installs exactly that build for you.

## Install

<Tabs>
  <Tab title="Windows">
    <Steps>
      <Step title="Download">
        Download the latest `ReSkate-<version>.zip` from [Releases](https://github.com/Dingo-Shenanigans/ReSkate/releases).
      </Step>
      <Step title="Extract">
        Extract `ReSkateLauncher.exe` and `ReSkate.dll` into a new, empty folder of their own, for example `C:\Games\ReSkate`.

        <Warning>Do not put them in Steam's skate. folder. ReSkate keeps its own copy of the game in its folder.</Warning>
      </Step>
      <Step title="Run the launcher">
        Run `ReSkateLauncher.exe`. It checks for ReSkate updates, then installs the supported build of the game into that folder.

        Sign in to Steam when asked, with the account that owns skate.: scan a QR code with the Steam app, or use your username and password with Steam Guard. On later runs the launcher checks the game files and downloads only what is missing.
      </Step>
      <Step title="Play">
        Press **PLAY**.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Linux (Proton)">
    <Steps>
      <Step title="Install skate.">
        Install skate. with Steam. Put `ReSkateLauncher.exe` and `ReSkate.dll` in a new, empty folder of their own, for example `~/Games/ReSkate`, not Steam's skate. folder: the launcher refuses to run from there.
      </Step>
      <Step title="Set the launch option">
        In Steam, open **skate. > Properties > Launch Options** and enter this, with your own folder's path:

        ```bash
        bash -c 'exec "${@/*EAAntiCheat.GameServiceLauncher.exe//home/you/Games/ReSkate/ReSkateLauncher.exe}"' -- %command%
        ```
      </Step>
      <Step title="Play">
        Press **Play** on skate. in your Steam library. The launcher installs its own copy of the game into that folder the first time.
      </Step>
    </Steps>

    Steam starts EA's anti-cheat launcher, not `Skate.exe`, and the anti-cheat refuses to run under Proton. The launch option swaps it for ReSkate's launcher, which starts the game itself. Launching from the game's own Steam entry, rather than adding the launcher as a non-Steam game, keeps skate.'s app ID and its Proton prefix.

    <Note>The launcher in a folder of its own has not been tested on Proton yet. Steam Deck should work the same way, but is untested.</Note>
  </Tab>
  <Tab title="macOS">
    Steam for Mac with a Wine-based compatibility tool (NotProton or CrossOver) works much the same way as Linux. [MACOS-SETUP.md](https://github.com/Dingo-Shenanigans/ReSkate/blob/main/MACOS-SETUP.md) has its launch option.
  </Tab>
</Tabs>

## Controls

| Key | Opens |
| --- | --- |
| **Insert** | The ReSkate menu |
| **~** (grave or tilde) | The command console. `help` lists the commands. |
| **T** | Chat, in multiplayer |

You can change the menu and console keys in the launcher's **Settings**.

## Mods

- Install mods on the launcher's **MODS** page: browse [Thunderstore](https://thunderstore.io/c/reskate/), or drag a `.zip` or a folder onto the window.
- **PROFILES** on that page saves which mods are on, and in what order, under a name. Profiles share as codes or `.r2z` files, the same ones r2modman uses.
- In game, the **MODS** tab of the ReSkate menu turns mods on and off and applies the changes. Most changes apply without a restart.
- Mods are checked against the game build they were made for. An outdated mod, or one that cannot be merged cleanly, is left out with a message naming it, and the rest still load.

<Warning>Only install mods you trust. Mods change game data.</Warning>

[Installing mods](/mods/installing) has the rest, and [Mods](/mods/overview) covers making them. Mods with code are plugins: to make one, start with the [plugin overview](/plugins/overview).

## Where things are

| What | Where |
| --- | --- |
| Mods | `Mods\<mod name>\` beside `Skate.exe`, ordered by `Mods\mods.json` |
| Logs | `logs\ReSkate.log` beside `Skate.exe` |
| Profile (skater, progress, parks) | `%LOCALAPPDATA%\ReSkate\profiles\offline\` |
| The game's own settings and saves | `%LOCALAPPDATA%\ReSkate\Game\`, kept apart from the normal game |
| Launcher settings | `ReSkateLauncher.settings.json` beside the launcher |

## Dedicated servers

`ReSkateServer.exe` is a headless lobby that needs neither the game nor Steam installed. [Dedicated servers](/servers/overview) covers running one. Each release has it in `ReSkateServer-<version>.zip` for Windows and `ReSkateServer-Linux-<version>.zip` for Linux. [Server/README.txt](https://github.com/Dingo-Shenanigans/ReSkate/blob/main/Server/README.txt) and [Server/README-linux.md](https://github.com/Dingo-Shenanigans/ReSkate/blob/main/Server/README-linux.md) cover setup, admin commands, votes and the anti-cheat checks. A server runs plugins too, from the `Plugins` folder beside it: see [server copies](/plugins/api/server).
