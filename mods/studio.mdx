ReSkate Studio is the Windows tool that makes the mods carrying game data: cosmetics of your own made from game items, replaced game textures, models, sounds, animations and effects, changed game values, props for plugins, and custom maps from Blender. It reads your installed skate. and writes only your mod, which carries the [build stamp](/mods/mod-folder#the-build-stamp) of the game build it was made for.

Each mod is a folder Studio builds, installs into ReSkate to test with **Test in game**, and packages for Thunderstore. Studio has its own tab on this site, which covers every part of it.

- [Overview](/studio/overview): what Studio makes and what it needs.
- [Your first mod](/studio/first-mod): from the first start to a mod in the game.
- [The window](/studio/window): the parts of the window and the keyboard shortcuts.
- [The mod's files](/studio/projects): the project folder, saving and undo.
- [Cosmetics](/studio/cosmetics): an item of your own from a game item.
- [Testing in the game](/studio/testing): the build, the install and its checks.
- [Troubleshooting](/studio/troubleshooting): the messages you may meet.

## Publishing

Studio's **Publish** page checks the mod and saves it as a Thunderstore package, with its `manifest.json`, `icon.png` and `README.md`. See [publishing](/studio/publishing), and [publishing on Thunderstore](/mods/thunderstore) for the package's fields.
